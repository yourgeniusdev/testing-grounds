# 04: Использовать общую готовность для ручной атаки и Наблюдения

**What to build:** Ручная атака и реакция ПВО расходуют одну готовность конкретного оружейного слота: применение одним способом исключает другой до обычного восстановления, а неиспользованный готовый зенитный слот сохраняет Наблюдение после завершения активации.

**Blocked by:** 03: Выполнять последовательные атаки оружием; этап 0, 06: Разрешать реакцию ПВО внутри манёвра.

**Status:** ready-for-agent

- [ ] Ручная атака зенитным слотом немедленно исключает его последующую реакцию до восстановления.
- [ ] Реакция ПВО немедленно исключает ручную атаку тем же слотом независимо от попадания.
- [ ] Другие оружейные слоты сохраняют независимую готовность.
- [ ] Наблюдение не создаёт отдельную копию оружия, боезапас или параллельный ресурс готовности.
- [ ] Неиспользованный готовый зенитный слот сохраняет Наблюдение при завершении активации, а не после каждой отдельной ручной атаки.
- [ ] Ручная и реактивная атаки используют один идентификатор слота, общий переход готовности и контекст конкретного действия.
- [ ] Сценарии ручной атаки без последующей реакции и сохранённого слота с последующей реакцией покрыты автоматическими тестами.
- [ ] `npm test`, `npm run typecheck`, `npm run lint` и `npm run build` проходят.
