# 03: Выполнять последовательные атаки оружием

**What to build:** После полного разрешения одной атаки игрок возвращается к выбору готового оружейного слота, может применить другой слот по той же или другой цели и явно завершить активацию, сохраняя временный запрет возврата к Манёвру после начала блока атак.

**Blocked by:** 02: Подтверждать одну атаку оружием.

**Status:** ready-for-agent

- [ ] Завершение атаки не завершает активацию автоматически и возвращает управление к выбору готового слота.
- [ ] Использованный слот недоступен, а другой готовый слот остаётся доступен при достаточном остатке энергии.
- [ ] Последовательные слоты могут атаковать разные цели или одну выжившую цель.
- [ ] Остаток энергии пересчитывается после каждой подтверждённой атаки и блокирует только фактически недоступные следующие атаки.
- [ ] Во время разрешения атаки нельзя начать другую атаку или завершить активацию; уничтожение активного юнита или победа не открывают новый выбор.
- [ ] Игрок явно завершает активацию из блока атак, после чего очередь корректно передаётся дальше.
- [ ] Временный адаптер запрещает возврат к Манёвру после начала блока атак и явно предназначен для удаления на этапе 3.
- [ ] Минимальный UI позволяет выбрать ровно один слот, увидеть его сектор и допустимые цели, выбрать одну цель, подтвердить атаку и после разрешения выбрать следующий слот.
- [ ] Переключение слота или отмена до подтверждения очищают неподтверждённую цель и не расходуют ресурсы; предпросмотр и hover не меняют состояние.
- [ ] Новые инварианты покрыты автоматическими тестами; `npm test`, `npm run typecheck`, `npm run lint` и `npm run build` проходят.
