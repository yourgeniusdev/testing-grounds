# 05: Удалить доменный контракт Залпа

**What to build:** Бой использует только отдельные атаки оружием: игрок после Манёвра применяет несколько готовых слотов по выбранным целям и явно завершает активацию, а устаревший контракт группового Залпа больше не влияет на домен, UI или разрешение атак.

**Blocked by:** 03: Выполнять последовательные атаки оружием; 04: Использовать общую готовность для ручной атаки и Наблюдения.

**Status:** ready-for-agent

- [ ] Публичный доменный контракт атаки принимает ровно один оружейный слот и одну цель; множественный выбор слотов и агрегированный предпросмотр удалены.
- [ ] Флаг `salvoCommitted` и зависящие от него сбросы, проверки и тестовые ожидания удалены из runtime-состояния.
- [ ] Временный адаптер Залпа из тикета 01 удалён после перевода UI и Наблюдения.
- [ ] Автоматическое завершение активации после атаки и устаревший пропуск Залпа удалены; завершение остаётся явным действием игрока.
- [ ] Непосредственно затронутые доменные события и UI используют термин «атака оружием» и контекст атакующего, слота, цели и действия.
- [ ] Сохраняются независимые Выстрелы, перезарядка, урон, пересчёт перекрытия и масштабирование Выстрелов эскадрильи.
- [ ] Сквозной сценарий «Манёвр → слот A по цели X → слот B по цели Y → завершить активацию» проходит без ручного исправления состояния.
- [ ] Предпросмотр и отмена не меняют состояние, а после начала блока атак временный запрет возврата к Манёвру остаётся до этапа 3.
- [ ] `npm test`, `npm run typecheck`, `npm run lint` и `npm run build` проходят.
