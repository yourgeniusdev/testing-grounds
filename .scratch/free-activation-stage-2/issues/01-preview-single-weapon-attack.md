# 01: Предпросматривать атаку одного оружейного слота

**What to build:** Игрок может выбрать один готовый оружейный слот и получить чистый предпросмотр его атаки по одной цели: сектор, дальность, допустимость и известные параметры рассчитываются для явного атакующего без изменения состояния боя. Существующий Залп временно использует те же правила через адаптер, удаляемый в тикете 05.

**Blocked by:** Этап 0, включая 06: Разрешать реакцию ПВО внутри манёвра; этап 1: Общий курс и Манёвренность.

**Status:** ready-for-agent

- [ ] Предпросмотр принимает явных атакующего, оружейный слот и цель и проверяет готовность, энергию, допустимый вид цели, сектор, дальность, линию огня и специальные запреты.
- [ ] Поддельные или не принадлежащие атакующему идентификаторы слота и цели отклоняются доменным слоем.
- [ ] Предпросмотр не меняет состояние, генератор случайных чисел, энергию, готовность, Наблюдение или события.
- [ ] Причины недоступности цели доступны UI без дублирования доменных правил.
- [ ] Эффективное число Выстрелов эскадрильи зависит от текущего размера стека, а не от устаревающего типа хардпоинта.
- [ ] Существующий Залп продолжает работать через временный адаптер к общим расчётам.
- [ ] Новые инварианты покрыты автоматическими тестами; `npm test`, `npm run typecheck`, `npm run lint` и `npm run build` проходят.
