# 02: Подтверждать одну атаку оружием

**What to build:** Игрок подтверждает применение одного выбранного оружейного слота по одной цели; домен повторно проверяет легальность, необратимо списывает энергию и готовность и полностью разрешает все независимые Выстрелы по зафиксированной цели.

**Blocked by:** 01: Предпросматривать атаку одного оружейного слота.

**Status:** ready-for-human

- [x] Подтверждение повторно проверяет актуальные состояние слота, энергию, цель, сектор, дальность и линию огня, не доверяя параметрам предпросмотра или UI.
- [x] Энергия и готовность списываются ровно один раз при подтверждении, до визуального разрешения; другие слоты не изменяются.
- [x] Случайные результаты определяются не раньше подтверждения и фиксируются в глубоко неизменяемом плане одного слота и одной цели.
- [x] Все Выстрелы разрешаются независимо по выбранной цели, а её уничтожение прекращает оставшиеся Выстрелы.
- [x] Каждая атака получает уникальный контекст действия и отдельный прогресс разрешения, включая две последовательные атаки того же юнита по той же цели.
- [x] Подтверждённую атаку нельзя отменить, перенаправить или прервать другим собственным действием.
- [x] Новые инварианты покрыты автоматическими тестами; `npm test`, `npm run typecheck`, `npm run lint` и `npm run build` проходят.
