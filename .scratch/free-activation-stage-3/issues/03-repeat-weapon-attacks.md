# 03: Возвращать выбор действий после атаки оружием

**What to build:** Подтверждённая атака одного готового оружейного слота по одной цели разрешается атомарно и возвращает игрока к выбору действий, позволяя в той же активации атаковать другим готовым слотом другую цель или выбрать действие другого типа.

**Blocked by:** 01: Ввести единый выбор действий активации; завершённый этап 2 — атаки отдельными оружейными слотами.

**Status:** ready-for-agent

- [ ] Планирование выбирает ровно один оружейный слот и одну цель, а смена слота или цели до подтверждения не расходует энергию и готовность.
- [ ] Подтверждение повторно проверяет готовность, энергию, вид цели, сектор, дальность и линию огня по текущему состоянию домена.
- [ ] Атака списывает энергию и готовность только выбранного слота и после всех его Выстрелов возвращает выбор действий без автоматического завершения активации.
- [ ] Другой готовый слот можно применить по другой цели в той же активации, используя общий остаток энергии.
- [ ] Ручная атака и Наблюдение используют одну готовность: использованный вручную слот не может реагировать, а сохранённый слот остаётся доступен для реакции.
- [ ] Манёвр между атаками заставляет следующую атаку заново вычислить цели, дальность, линию огня и сектор из текущих гекса и курса.
- [ ] Атака не сбрасывает расходы Скорости, Манёвренности или накопленное Уклонение.
- [ ] Из текущего UI и событий этого сквозного пути удалены термин «Залп» и требование сначала перейти в фазу атаки.
- [ ] Интеграционный сценарий выполняет атаки двумя слотами по разным целям и явно завершает активацию после них.
