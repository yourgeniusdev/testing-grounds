# 06: Применять эффект нахождения на границах манёвра

**What to build:** Эффект нахождения разрешается в фактическом конечном гексе после каждого манёвра, а при завершении активации без единого манёвра — ровно один раз, независимо от других выполненных действий.

**Blocked by:** 02: Разрешить повторные манёвры на остатках ресурсов.

**Status:** ready-for-agent

- [ ] После полного манёвра эффект нахождения применяется один раз в фактическом конечном гексе до возврата к выбору действий.
- [ ] Манёвр только из поворотов считается манёвром и применяет эффект нахождения в текущем гексе.
- [ ] Досрочная остановка из-за препятствия, опасности или Перехвата применяет эффект в реально достигнутом гексе, а не в запланированном конечном.
- [ ] Каждый из нескольких манёвров одной активации отдельно применяет эффект нахождения.
- [ ] Явное завершение активации без манёвров применяет эффект нахождения ровно один раз, даже если выполнялись атаки или системные действия.
- [ ] Завершение после хотя бы одного разрешённого манёвра не применяет эффект повторно.
- [ ] Предпросмотр, отмена и не начатый манёвр не отмечают манёвр выполненным и не запускают эффект.
- [ ] Если эффект уничтожает активный юнит, действие и активация завершаются согласованно без возврата управления уничтоженному юниту.
- [ ] Событие эффекта связано с конкретным манёвром либо с явным завершением активации без манёвров.
