# 07: Накапливать Уклонение по фактическому движению

**What to build:** Уклонение активного юнита отражает все фактически исполненные шаги и предусмотренные формулой повороты нескольких манёвров текущей активации и сохраняется при чередовании с атаками и системными действиями.

**Blocked by:** 02: Разрешить повторные манёвры на остатках ресурсов.

**Status:** ready-for-agent

- [ ] Исполнитель сообщает фактически выполненные элементы каждого манёвра, а расчёт Уклонения использует их вместо запланированного маршрута.
- [ ] Шаги нескольких манёвров одной активации суммируются по действующей формуле Уклонения.
- [ ] Неисполненный хвост досрочно остановленного маршрута не увеличивает Уклонение.
- [ ] Повышенная стоимость входа в местность расходует Скорость, но не считается дополнительными шагами.
- [ ] Манёвр только из поворотов влияет на Уклонение ровно так, как определяет действующая формула.
- [ ] Атака оружием и системное действие между манёврами не сбрасывают накопленное Уклонение.
- [ ] Предпросмотр и отмена маршрута не меняют Уклонение.
- [ ] Накопленные факты движения сбрасываются только в следующем Начале активации согласно правилам.
- [ ] UI после каждого действия показывает Уклонение, вычисленное из тех же подтверждённых фактов, что и домен.
