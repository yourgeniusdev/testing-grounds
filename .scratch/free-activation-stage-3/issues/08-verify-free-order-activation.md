# 08: Удалить фазовые адаптеры и проверить свободный порядок

**What to build:** Полный бой использует целевую свободную активацию без фазовой оркестрации: игрок чередует манёвры, атаки отдельных слотов и системные действия, затем явно завершает активацию, а UI и события объясняют доступность через конкретные действия и остатки ресурсов.

**Blocked by:** 02: Разрешить повторные манёвры на остатках ресурсов; 03: Возвращать выбор действий после атаки оружием; 04: Разрешить системные действия между другими действиями; 05: Сохранять расходы при изменении максимумов ресурсов; 06: Применять эффект нахождения на границах манёвра; 07: Накапливать Уклонение по фактическому движению.

**Status:** ready-for-agent

- [ ] Интеграционный сценарий выполняет «манёвр → атака → системное действие → манёвр → атака другим слотом → явное завершение» и сохраняет корректные остатки ресурсов после каждого шага.
- [ ] Из доменной легальности удалены зависимости от последовательности `system → movement → attack`, автоматический переход к атаке и автоматическое завершение после атаки.
- [ ] Удалены временные адаптеры этапов 1 и 2, включая единственный манёвр перед атакой и старый контракт Залпа.
- [ ] Завершение активации не требует пропустить атаку и корректно отменяет неподтверждённый предпросмотр без оплаты.
- [ ] UI не строит маршрут до выбора манёвра, показывает доступные действия и причины блокировки и не использует текущую терминологию фаз или Залпа.
- [ ] События манёвров, шагов, опасностей, реакций, атак, урона и уничтожения связаны с конкретным подтверждённым действием и причинным контекстом.
- [ ] Уничтожение активного юнита внутри манёвра, атаки или реакции корректно завершает управление им, обновляет инициативу и позволяет определить победителя.
- [ ] Предпросмотр и отмена ни в одном интеграционном сценарии не меняют состояние боя.
- [ ] Существующий боевой сценарий можно завершить без ручного исправления состояния.
- [ ] `npm test`, `npm run typecheck`, `npm run lint` и `npm run build` проходят.
