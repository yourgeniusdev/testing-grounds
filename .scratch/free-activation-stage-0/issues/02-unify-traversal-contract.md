# 02: Объединить контракт проходимости и предпросмотр маршрута

**What to build:** Игрок получает одинаково рассчитанные стоимость, допустимость остановки и известные последствия маршрута для обеих категорий юнитов, причём всё совместимое содержимое каждого гекса учитывается одновременно.

**Blocked by:** 01: Характеризовать планирование маршрутов.

**Status:** ready-for-agent

- [ ] Планировщик крупного корабля и планировщик эскадрильи используют один контракт стоимости входа и проходимости.
- [ ] Крупный корабль не входит в гекс любого юнита, а объект блокирует обе категории юнитов.
- [ ] Эскадрилья может пройти через крупный корабль, но не может завершить там манёвр.
- [ ] Присутствие крупного корабля не скрывает стоимость местности, опасности и прочее совместимое содержимое того же гекса.
- [ ] Пролёт эскадрильи через крупный корабль в поле обломков или астероидное поле использует стоимость входа для эскадрильи.
- [ ] Опасность в занятом крупным кораблём гексе остаётся видимой в предпросмотре маршрута.
- [ ] Гекс, запрещённый для остановки, используется только как промежуточный, если у маршрута есть оплачиваемое законное продолжение.
- [ ] Существующие UI-опции манёвра продолжают показывать стабильный идентификатор, конечное состояние, ресурсы и известные последствия без изменения состояния боя.
