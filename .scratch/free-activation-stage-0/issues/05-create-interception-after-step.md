# 05: Создавать Перехват после фактического шага

**What to build:** После входа эскадрильи в новый гекс система связывает её Перехватом со всеми подходящими соседними врагами, немедленно прекращает маршрут и не позволяет связанной эскадрилье начинать обычный манёвр.

**Blocked by:** 04: Разрешать опасности и уничтожение в фактическом гексе.

**Status:** ready-for-agent

- [ ] Перехват проверяется только после успешно выполненного фактического шага выжившей эскадрильи.
- [ ] Связи создаются со всеми подходящими соседними вражескими эскадрильями, без дубликатов и в стабильном порядке.
- [ ] Каждая связь симметрично присутствует у обеих эскадрилий.
- [ ] Союзные эскадрильи и сам пролёт через крупный корабль не создают Перехват.
- [ ] Шаг, создавший хотя бы одну связь, становится последним шагом текущего маршрута; оставшиеся элементы не исполняются.
- [ ] Связанная эскадрилья не получает доступных опций обычного манёвра.
- [ ] Уничтожение участника удаляет все его взаимные связи, не затрагивая связи между оставшимися эскадрильями.
- [ ] Предпросмотр сообщает полный набор ожидаемых связей, а прежнее одиночное поле UI сохраняется как детерминированный временный адаптер.
- [ ] Адаптер одиночного Перехвата явно назначен к удалению после перевода UI на полный набор связей.
