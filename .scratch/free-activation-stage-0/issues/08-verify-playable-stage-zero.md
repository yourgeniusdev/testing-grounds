# 08: Зафиксировать играбельный результат этапа 0

**What to build:** Полный бой использует новый пошаговый фундамент движения, оставаясь внешне совместимым с прежней последовательностью одного манёвра и блока атаки, и корректно завершается во всех ключевых сценариях этапа 0.

**Blocked by:** 01: Характеризовать планирование маршрутов; 02: Объединить контракт проходимости и предпросмотр маршрута; 03: Исполнять неизменяемый план манёвра пошагово; 04: Разрешать опасности и уничтожение в фактическом гексе; 05: Создавать Перехват после фактического шага; 06: Разрешать реакцию ПВО внутри манёвра; 07: Учитывать все известные последствия в политиках маршрута.

**Status:** ready-for-agent

- [ ] Интеграционный сценарий проходит обычный манёвр, опасность, реакцию ПВО, Перехват, досрочную остановку и переход к прежнему блоку атаки.
- [ ] Сценарий пролёта эскадрильи через крупный корабль сохраняет прочее содержимое гекса и разрешает его стоимость и последствия.
- [ ] Уничтожение активного юнита опасностью или реакцией завершает действие без ручного исправления состояния, корректно обновляет инициативу и позволяет определить победителя.
- [ ] Все манёвры в игровом сценарии изменяют позицию только через пошаговый исполнитель; прямой перенос в конечную точку не используется.
- [ ] События содержат контекст конкретного манёвра, шага и причины, а не зависят от устаревшего названия фазы.
- [ ] Сохраняются различия этапа 0: эскадрильи без курса, один поворот крупного корабля перед шагом, один финальный доворот, один манёвр перед старым Залпом.
- [ ] Перечислены временные адаптеры: курс эскадрилий и синтез конечного курса удаляются на этапе 1; старый Залп — на этапе 2; один манёвр перед атакой и фазовая оркестрация — на этапе 3; одиночное поле Перехвата — после перевода UI на полный набор связей.
- [ ] Предпросмотр и отмена ни в одном интеграционном сценарии не меняют состояние боя.
- [ ] `npm test`, `npm run typecheck`, `npm run lint` и `npm run build` проходят.
