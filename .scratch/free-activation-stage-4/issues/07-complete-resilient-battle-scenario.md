# 07: Пройти устойчивый интеграционный бой

**What to build:** Один воспроизводимый полный бой подтверждает, что свободная активация остаётся проходимой при сочетании нескольких целей, опасностей, ПВО, Перехвата, Отрыва, изменения характеристик и уничтожения внутри действия.

**Blocked by:** 02: Сохранять Наблюдение при свободной активации; 03: Продолжать активацию после Отрыва на остатки бюджетов; 04: Пересчитывать действия после изменения характеристик; 05: Безопасно завершать действие при уничтожении активного юнита; 06: Объяснять доступность каждого действия.

**Status:** ready-for-agent

- [ ] Сценарий проходит развёртывание, Начало активации, свободное чередование действий, явное завершение активаций и штатное завершение боя.
- [ ] Один юнит атакует разными готовыми оружейными слотами разные допустимые цели, а промежуточный манёвр меняет сектор или дальность следующей атаки.
- [ ] Фактический шаг разрешает опасность и реакцию ПВО до продолжения маршрута; сохранённая готовность расходуется ровно один раз.
- [ ] Эскадрилья получает Перехват от нескольких врагов, выполняет Отрыв и маневрирует на оставшиеся бюджеты.
- [ ] Изменение текущего максимума ресурса между действиями сохраняет выполненный расход и обновляет доступность следующего действия.
- [ ] Уничтожение активного юнита внутри манёвра или реакции прекращает недопустимые последующие результаты и корректно продолжает либо завершает бой.
- [ ] Журнал имеет детерминированный контекст действий и причинный порядок, а предпросмотры и отмены не меняют состояние.
- [ ] `npm test`, `npm run typecheck`, `npm run lint` и `npm run build` проходят.
