# 06: Объяснять доступность каждого действия

**What to build:** Панель действий показывает только актуальные возможности юнита и для каждого недоступного выбора объясняет доменную причину, стоимость и состояние общих ресурсов, не выводя легальность из прежних фаз или доверенных данных UI.

**Blocked by:** 02: Сохранять Наблюдение при свободной активации; 03: Продолжать активацию после Отрыва на остатки бюджетов; 04: Пересчитывать действия после изменения характеристик; 05: Безопасно завершать действие при уничтожении активного юнита.

**Status:** ready-for-agent

- [ ] Манёвр, Отрыв, системные действия, каждый оружейный слот и завершение активации используют общий доменный результат доступности.
- [ ] Результат содержит стабильные причины блокировки, прогноз стоимости и актуальные максимум, расход и остаток затрагиваемых ресурсов.
- [ ] Причины различают нехватку ресурса, отсутствие готовности, Перехват, недопустимую цель, сектор, дальность, линию огня и разрешение другого действия.
- [ ] UI использует этот результат для кнопок, подсказок, предпросмотра и отображения остатков без собственной повторной реализации правил.
- [ ] Подтверждение команды повторно получает доменный результат и отклоняет устаревший или подменённый ввод UI без изменения боя.
- [ ] После каждого разрешённого действия и реакции доступность и остатки обновляются до следующего выбора игрока.
- [ ] Автоматические тесты сопоставляют показанную причину с фактическим решением доменной валидации для ключевых действий.
