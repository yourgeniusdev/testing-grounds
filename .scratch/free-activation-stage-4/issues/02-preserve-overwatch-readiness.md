# 02: Сохранять Наблюдение при свободной активации

**What to build:** Игрок может осознанно использовать зенитный оружейный слот вручную либо сохранить его для Наблюдения; при фактическом входе вражеской эскадрильи реакция разрешается внутри манёвра, расходует ту же готовность и объясняется в журнале.

**Blocked by:** 01: Показывать манёвр в журнале с контекстом действия.

**Status:** ready-for-agent

- [ ] Ручная атака зенитным оружейным слотом расходует его готовность и исключает последующую реакцию до восстановления.
- [ ] Готовый неиспользованный слот сохраняет Наблюдение после действий владельца и реагирует только на допустимую цель в актуальных секторе и дальности.
- [ ] Реакция повторно проверяет допустимость непосредственно перед объявлением, разрешает все Выстрелы по обычным правилам и расходует готовность независимо от попадания.
- [ ] Несколько допустимых реакций разрешаются в стабильном порядке, а уничтожение движущейся эскадрильи прекращает оставшиеся реакции и элементы маршрута.
- [ ] Реакция не запускается внутри обычной атаки оружием и не открывает окно для собственного действия между элементами подтверждённого манёвра.
- [ ] После реакции UI показывает актуальную готовность слота, а журнал связывает реакцию с вызвавшим её фактическим шагом.
- [ ] Автоматические тесты покрывают вручную использованный слот, сохранённый слот, промах, успешное попадание и уничтожение движущейся эскадрильи.
