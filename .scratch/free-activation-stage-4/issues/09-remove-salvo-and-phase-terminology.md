# 09: Удалить терминологию Залпа и фаз

**What to build:** Игровой UI, доступность действий, журнал и текущие доменные события последовательно называют Активацию, Манёвр и Атаку оружием и больше не представляют свободный порядок действий как Залп или необратимые фазы.

**Blocked by:** 08: Доработать UI ПВО и Перехвата.

**Status:** ready-for-agent

- [ ] Видимые подписи, кнопки, причины блокировки, журнал и ARIA-тексты используют актуальную доменную терминологию.
- [ ] Текущие события описывают контекст активации и конкретного действия без поля или значения фазы.
- [ ] Удалены оставшиеся рабочие адаптеры старого Залпа, фазовой оркестрации и одиночного представления Перехвата.
- [ ] Поиск по исполняемому коду и актуальной документации не находит Залп или фазу как название текущей механики.
- [ ] Явно архивные исторические документы не переписываются и не считаются нарушением критерия.
- [ ] Полный интеграционный сценарий остаётся проходимым после удаления адаптеров.
- [ ] `npm test`, `npm run typecheck`, `npm run lint` и `npm run build` проходят.
