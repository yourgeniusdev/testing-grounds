# 04: Пересчитывать действия после изменения характеристик

**What to build:** Когда системное действие между манёврами, атаками или другими действиями изменяет текущий максимум ресурса, игрок сразу получает корректный новый набор действий и остатков без отмены уже совершённого расхода.

**Blocked by:** 01: Показывать манёвр в журнале с контекстом действия.

**Status:** ready-for-agent

- [ ] Для Скорости, Манёвренности и энергии остаток определяется актуальным максимумом и накопленным расходом и никогда не становится отрицательным.
- [ ] Уменьшение максимума не возвращает и не переписывает выполненный расход, но может закрыть ранее доступное действие.
- [ ] Увеличение максимума сохраняет расход и может открыть новый манёвр, системное действие или атаку оружием.
- [ ] После подтверждённого изменения характеристик доступная сетка, допустимые цели и панель действий пересчитываются из актуального состояния.
- [ ] Неподтверждённый предпросмотр при изменении исходного состояния признаётся устаревшим и не может быть подтверждён без повторной валидации.
- [ ] UI единообразно показывает актуальные максимум, расход и остаток каждого общего ресурса активации.
- [ ] Автоматический сценарий покрывает уменьшение и увеличение характеристики между двумя действиями одной активации.
