# 05: Провести автопушку «Осы» через передний хардпоинт

**What to build:** Автопушка «Осы» использует направленный эскадрильный хардпоинт и выбирает цели только в переднем секторе относительно текущего Курса. Доменная проверка и UI-подсветка совпадают, а число Выстрелов продолжает масштабироваться текущим стеком.

**Blocked by:** 01: Дать эскадрильям Манёвренность и обязательный Курс.

**Status:** ready-for-agent

- [ ] Конфигурация и её валидатор поддерживают направленный передний хардпоинт эскадрильи без смешения типа совместимости оружия и геометрии сектора.
- [ ] Автопушка «Осы» принимает цель в переднем секторе и отклоняет цель позади для всех шести Курсов.
- [ ] UI-подсветка сектора совпадает с доменной проверкой допустимости цели.
- [ ] Число Выстрелов сохраняет масштабирование для стеков 3, 2 и 1 независимо от геометрии хардпоинта.
- [ ] Старый Залп остаётся способом подтверждения атаки на этом этапе.
- [ ] Круговые хардпоинты «Мантиса» временно продолжают работать и явно помечены для удаления в тикете 06.
- [ ] Интеграционная проверка изменения сектора после Манёвра выполняется в тикете 07 после завершения общего движения эскадрилий.
- [ ] Автоматические тесты покрывают конфигурацию, шесть Курсов, UI-сектор и масштабирование Выстрелов.
