# 05: Провести автопушку «Осы» через передний хардпоинт

**What to build:** Автопушка «Осы» использует направленный эскадрильный хардпоинт и выбирает цели только в переднем секторе относительно текущего Курса. Доменная проверка и UI-подсветка совпадают, а число Выстрелов продолжает масштабироваться текущим стеком.

**Blocked by:** 01: Дать эскадрильям Манёвренность и обязательный Курс.

**Status:** resolved

- [x] Конфигурация и её валидатор поддерживают направленный передний хардпоинт эскадрильи без смешения типа совместимости оружия и геометрии сектора.
- [x] Автопушка «Осы» принимает цель в переднем секторе и отклоняет цель позади для всех шести Курсов.
- [x] UI-подсветка сектора совпадает с доменной проверкой допустимости цели.
- [x] Число Выстрелов сохраняет масштабирование для стеков 3, 2 и 1 независимо от геометрии хардпоинта.
- [x] Старый Залп остаётся способом подтверждения атаки на этом этапе.
- [x] Круговые хардпоинты «Мантиса» временно продолжают работать и явно помечены для удаления в тикете 06.
- [x] Интеграционная проверка изменения сектора после Манёвра выполняется в тикете 07 после завершения общего движения эскадрилий.
- [x] Автоматические тесты покрывают конфигурацию, шесть Курсов, UI-сектор и масштабирование Выстрелов.

## Comments

- Реализовано 2026-10-31 в зависимости от тикета 01: runtime-оружие сохраняет отдельное поле геометрии `firingArc`, тогда как `hardpointType: squadronWeapon` продолжает отвечать только за совместимость каталога.
- Автопушка «Осы» использует `firingArc: forward`; доменная проверка цели и `attackArc`, используемый подсветкой UI, проходят через одну геометрию и текущий runtime-Курс.
- Масштабирование Выстрелов теперь привязано к владельцу-эскадрилье, а не к геометрии или названию mount, и покрыто для стеков 3, 2 и 1.
- Промежуточное состояние с круговыми слотами «Мантиса» существовало только между тикетами 05 и 06; тикет 06 выполнен сразу следом и удалил его из итогового дерева.
- Старый Залп не изменялся. Проверку смены сектора после фактического Манёвра оставили тикету 07, поскольку она зависит от общего планировщика/исполнителя тикетов 02–04.
