# 02: Исполнять Манёвр только из поворотов

**What to build:** Игрок может выполнить в текущем гексе настоящий Манёвр из одного или нескольких поворотов на 60°, увидеть его стоимость, подтвердить и получить новый Курс через общий пошаговый исполнитель. Пустой Манёвр не предлагается и не может быть подтверждён, а после завершения сохраняется прежний переход к старому Залпу.

**Blocked by:** 01: Дать эскадрильям Манёвренность и обязательный Курс.

**Status:** resolved

- [x] Текущий гекс доступен как конечное состояние только с Курсом, отличающимся от исходного.
- [x] Каждый поворот является отдельным неизменяемым элементом плана, расходует 1 Манёвренность и не расходует Скорость.
- [x] При достаточном бюджете доступны последовательные повороты на 120° и 180°.
- [x] Исходная пара «гекс + Курс» отсутствует среди UI-опций и отклоняется при доменном подтверждении.
- [x] Подтверждённые повороты исполняются по одному и обновляют runtime-Курс только через общий исполнитель плана Манёвра.
- [x] Предпросмотр и отмена не меняют состояние боя; после завершения Манёвра открывается старый Залп.
- [x] Отдельные пути поворота на месте и пропуска движения удалены как альтернативные способы изменения Курса.
- [x] Автоматические тесты покрывают стоимость, последовательные повороты, запрет пустого Манёвра, отмену и доменную повторную валидацию.

## Comments

- Реализовано 2026-10-31: поворот на месте теперь является обычным маршрутом с неизменяемыми элементами `turn`; пустая исходная пара не публикуется и повторно отклоняется при подтверждении.
- Удалены отдельные доменные команды поворота и пропуска движения; завершённый turn-only Манёвр переходит в прежний этап атаки.
- Проверено focused-наборами маршрутизации, исполнения, UI и интеграции этапа 0.
