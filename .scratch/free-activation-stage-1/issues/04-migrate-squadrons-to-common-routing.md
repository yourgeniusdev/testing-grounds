# 04: Перевести эскадрильи на общий планировщик и исполнитель

**What to build:** «Оса» и «Мантис» используют ту же последовательность «поворот или шаг», что и крупные корабли: двигаются только по текущему Курсу, расходуют профильную Манёвренность и сохраняют фактический конечный Курс. Категорийные различия остаются только в проходимости, массе, Перехвате и реакциях.

**Blocked by:** 03: Перевести крупные корабли на поиск «поворот или шаг».

**Status:** resolved

- [x] Один поисковый движок строит маршруты крупных кораблей и эскадрилий.
- [x] Шаг эскадрильи выполняется только по её текущему Курсу, а каждый поворот расходует Манёвренность.
- [x] Эскадрилья может несколько раз повернуть до, между и после шагов; её конечное состояние всегда содержит гекс и Курс.
- [x] Сохраняются правила этапа 0: пролёт через крупный корабль без остановки, стоимость и содержимое гекса, пошаговые опасности, ПВО и Перехват.
- [x] Возникновение Перехвата прекращает оставшийся маршрут, а связанная эскадрилья не получает опций обычного Манёвра.
- [x] Анимация следует элементам подтверждённого плана и сохраняет фактический конечный Курс.
- [x] Отдельный планировщик эскадрильи, конечные состояния без Курса и синтез визуального Курса из направления шага удалены.
- [x] Автоматические тесты сравнивают общую механику обеих категорий и отдельно фиксируют различия их проходимости и реакций.

## Comments

- Реализовано 2026-10-31: категории используют один поисковый движок и один исполнитель; различия остались в `traversal`, предпросмотре/разрешении реакций и Перехвате.
- Эскадрильи сохраняют runtime-Курс на каждом `turn` и двигаются только по нему; анимация читает переходы подтверждённого плана.
