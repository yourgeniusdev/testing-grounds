# 07: Зафиксировать играбельный результат этапа 1

**What to build:** Полный бой демонстрирует общую механику Курса и Манёвренности для крупных кораблей и эскадрилий, направленные сектора всего текущего эскадрильного оружия и сохранение пошагового фундамента этапа 0. Активация намеренно остаётся совместимой со сценарием «один Манёвр → старый Залп» до следующих этапов миграции.

**Blocked by:** 04: Перевести эскадрильи на общий планировщик и исполнитель; 06: Перевести все слоты «Мантиса» на передний сектор.

**Status:** ready-for-agent

- [ ] Полный сценарий проходит расстановку обеих сторон, Манёвр, старый Залп, завершение активации и переход к следующему юниту.
- [ ] Крупный корабль выполняет несколько поворотов между шагами либо разворот на 180° со следующим шагом.
- [ ] Эскадрилья выполняет повороты и шаги, сохраняет конечный Курс и корректно проходит через крупный корабль.
- [ ] Опасность, ПВО, уничтожение и Перехват продолжают разрешаться по фактическим элементам плана этапа 0.
- [ ] После Манёвра сектор каждого слота эскадрильи соответствует фактическому конечному Курсу.
- [ ] Пустой Манёвр отсутствует, а Манёвр только из поворотов доступен.
- [ ] Предпросмотр и отмена не изменяют состояние; позиция и Курс меняются только пошаговым исполнителем.
- [ ] Удалены категорийный dispatch планировщика, конечные состояния без Курса, синтетические финальные Курсы и старые круговые хардпоинты текущих эскадрилий.
- [ ] Временная совместимость перечислена явно: старый Залп удаляется на этапе 2, ограничение одного Манёвра и фазовая оркестрация — на этапе 3.
- [ ] `npm test`, `npm run typecheck`, `npm run lint` и `npm run build` проходят.
