# 01: Дать эскадрильям Манёвренность и обязательный Курс

**What to build:** После сценарного или ручного развёртывания каждая эскадрилья имеет профильную Манёвренность и видимый Курс, автоматически назначенный по стороне: левая сторона ориентирована вправо, правая — влево. Домен остаётся источником истины, поэтому UI не может подменить начальный Курс.

**Blocked by:** Этап 0 / 08: Зафиксировать играбельный результат этапа 0.

**Status:** resolved

- [x] Профили «Осы» и «Мантиса» содержат неотрицательную Манёвренность, явно превышающую значение сопоставимого крупного корабля без использования системного минимума.
- [x] Профиль и runtime-состояние эскадрильи содержат Манёвренность, её расход и остаток, а также валидный Курс из шести направлений.
- [x] Все сценарные и размещаемые вручную юниты левой стороны получают Курс вправо, а правой стороны — влево.
- [x] Переданный UI произвольный Курс не может обойти доменное правило стороны развёртывания.
- [x] Ориентация «Осы» и «Мантиса» видна на поле и в предпросмотре без изменения состояния боя.
- [x] Временная совместимость явно зафиксирована: отдельный планировщик эскадрильи пока игнорирует новые Курс и Манёвренность и удаляется в тикете 04.
- [x] Автоматические тесты покрывают профили, runtime-состояние, обе стороны развёртывания и невозможность подмены Курса через UI.

## Comments

- Реализовано 2026-10-31: «Оса» получила Манёвренность 5, «Мантис» — 4; оба значения валидируются и превышают показатели сопоставимых крупных кораблей.
- Домен назначает Курс 0 всем юнитам левой стороны и Курс 3 всем юнитам правой стороны как в сценарии, так и при ручном размещении; переданный UI Курс игнорируется.
- Runtime хранит `heading`, `maneuver`, `maneuverSpent` и `maneuverRemaining`; поле и предпросмотр используют runtime-Курс эскадрильи без изменения боя.
- Временный адаптер до тикета 04: `planSquadronRoutes` намеренно сохраняет свободный выбор соседнего направления и не расходует новые Курс/Манёвренность. Тикеты 02 и 05 могут считать наличие валидного runtime-Курса и бюджетов гарантированным.
- Проверено: focused tests 55/55; полный `npm.cmd test` 128/128; `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd run build` прошли.
