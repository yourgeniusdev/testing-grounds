# 03: Перевести крупные корабли на поиск «поворот или шаг»

**What to build:** Крупный корабль строит Манёвр как произвольную последовательность поворотов и шагов в пределах остатков Скорости и Манёвренности. Для каждой достижимой пары «конечный гекс + конечный Курс» игрок получает один воспроизводимый маршрут, который исполняется пошагово и сохраняет правила проходимости этапа 0.

**Blocked by:** 02: Исполнять Манёвр только из поворотов.

**Status:** ready-for-agent

- [ ] Состояние поиска учитывает гекс, Курс, расходы Скорости и Манёвренности, посещённые гексы и известные последствия.
- [ ] Повороты разрешены до первого, между любыми и после последнего шага; при нулевой Манёвренности доступны только шаги прямо.
- [ ] Крупный корабль с Манёвренностью 3 может развернуться на 180° и затем сделать шаг по новому Курсу.
- [ ] Один маршрут не посещает один гекс повторно, при этом повороты в текущем гексе не считаются повторным посещением.
- [ ] Разные конечные Курсы одного гекса представлены отдельными достижимыми состояниями.
- [ ] Для каждой пары «гекс + Курс» маршрут выбирается по приоритету: Скорость, Манёвренность, ожидаемый известный вред, стабильный геометрический порядок.
- [ ] Стоимость каждого шага и известные последствия берутся из общего контракта проходимости этапа 0.
- [ ] Ограничение одного поворота перед шагом и синтетический финальный доворот удалены; UI показывает настоящие конечные состояния плана.
- [ ] Автоматические тесты покрывают повороты до, между и после шагов, разворот со следующим шагом, разные конечные Курсы и детерминированность.
