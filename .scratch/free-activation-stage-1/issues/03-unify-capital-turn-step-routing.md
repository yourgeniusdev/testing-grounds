# 03: Перевести крупные корабли на поиск «поворот или шаг»

**What to build:** Крупный корабль строит Манёвр как произвольную последовательность поворотов и шагов в пределах остатков Скорости и Манёвренности. Для каждой достижимой пары «конечный гекс + конечный Курс» игрок получает один воспроизводимый маршрут, который исполняется пошагово и сохраняет правила проходимости этапа 0.

**Blocked by:** 02: Исполнять Манёвр только из поворотов.

**Status:** resolved

- [x] Состояние поиска учитывает гекс, Курс, расходы Скорости и Манёвренности, посещённые гексы и известные последствия.
- [x] Повороты разрешены до первого, между любыми и после последнего шага; при нулевой Манёвренности доступны только шаги прямо.
- [x] Крупный корабль с Манёвренностью 3 может развернуться на 180° и затем сделать шаг по новому Курсу.
- [x] Один маршрут не посещает один гекс повторно, при этом повороты в текущем гексе не считаются повторным посещением.
- [x] Разные конечные Курсы одного гекса представлены отдельными достижимыми состояниями.
- [x] Для каждой пары «гекс + Курс» маршрут выбирается по приоритету: Скорость, Манёвренность, ожидаемый известный вред, стабильный геометрический порядок.
- [x] Стоимость каждого шага и известные последствия берутся из общего контракта проходимости этапа 0.
- [x] Ограничение одного поворота перед шагом и синтетический финальный доворот удалены; UI показывает настоящие конечные состояния плана.
- [x] Автоматические тесты покрывают повороты до, между и после шагов, разворот со следующим шагом, разные конечные Курсы и детерминированность.

## Comments

- Реализовано 2026-10-31: общий поиск работает по действиям `turn | move`, хранит посещённые гексы и ключует результаты парой «гекс + Курс».
- Приоритет маршрутов сохранён: стоимость Скорости, повороты, ожидаемый известный вред, стабильный код действий; стоимость и последствия шага продолжают поступать из `traversal`.
- UI получает фактические конечные состояния маршрута без синтетического финального поворота.
