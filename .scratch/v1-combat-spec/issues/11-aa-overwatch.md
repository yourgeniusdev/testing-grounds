# Автоматическое наблюдение ПВО

Type: grilling
Status: resolved
Blocked by: 01, 04

## Question

Определить автоматический переход каждого неиспользованного подходящего зенитного слота в наблюдение после активации. Реакция срабатывает при входе вражеской эскадрильи в сектор и дальность, расходует готовность конкретного слота; несколько реакций разрешаются по инициативе владельцев и порядку слотов, оставшиеся отменяются после уничтожения цели.

## Answer

После активации все подходящие неиспользованные зенитные слоты автоматически переходят в наблюдение. Подходящим считается живой готовый слот с доступным боезапасом, чей сектор, дальность и тип оружия допускают поражение цели. Наблюдение проверяется при входе вражеской эскадрильи в допустимые сектор и дальность; одна эскадрилья может вызвать реакции нескольких подходящих слотов, включая несколько слотов одного юнита. Реакции сортируются по инициативе владельцев, затем по стабильному порядку слотов. Перед каждой реакцией повторно проверяется валидность цели; уничтожение или иная невалидность цели отменяет оставшиеся реакции без возврата уже израсходованной готовности. Готовность слота расходуется при объявлении реакции, независимо от результата броска.

Каждый слот наблюдения может сработать не более одного раза за раунд против одной цели. После срабатывания слот снимается с наблюдения. Если за раунд срабатывания не произошло, наблюдение всех таких слотов сбрасывается в конце раунда. Выход цели из сектора сам по себе не расходует слот; повторный вход до конца раунда может вызвать его реакцию. Наблюдение включается сразу после начала активации, до первого действия активируемой стороны.
