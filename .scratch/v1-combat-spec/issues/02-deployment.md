# Правила стартовой расстановки сторон

Type: grilling
Status: resolved
Assignee: main
Blocked by: 01

## Question
Специфицировать последовательную расстановку целой стороны в зоне шириной два гекса от её края по всей высоте поля: сначала левая сторона, затем правая; только полностью свободные зелёные гексы, любой курс капитального корабля, подтверждение стороны, невозможность последующего редактирования и формирование инициативы после подтверждения обеих сторон.

## Resolution
Левая сторона первой размещает весь флот, затем правая. Для каждой стороны доступны ровно два ближайших к её краю гексальных слоя по всей высоте поля; допустим только полностью свободный зелёный гекс, не занятый ранее размещённым юнитом. До подтверждения сторона может менять позиции своих юнитов и курсы; после подтверждения её расстановка неизменяема. Курс капитального корабля при размещении выбирается свободно. Подтверждение второй стороны создаёт начальную инициативу и переводит бой в ожидание первого активного юнита. Генерация поля обязана исключать расклады, в которых допустимых гексов недостаточно для размещения полного состава флота.

Решение принято по итогам grilling-сессии с доменным уточнением терминов зоны размещения, подтверждения и начальной инициативы.
