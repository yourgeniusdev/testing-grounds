# Дискретная модель линии огня и перекрытия

Type: prototype
Status: resolved

## Answer

Линия огня v1 строится дискретно по центрам исходного и целевого гексов алгоритмом supercover: учитываются все гексы, которых касается отрезок, включая оба гекса при прохождении ровно по общей грани; граничное прохождение не считается промахом. Гексы проверяются от стрелка к цели. Эскадрильи и малые объекты не создают перекрытия. Из объектов, создающих перекрытие, учитывается только ближайший к стрелку объект. Если на граничном участке только один из затронутых гексов содержит способный перекрывать объект, выбирается он; пустой гекс не создаёт альтернативы. Если подходящие объекты есть в обоих гексах, применяется детерминированный tie-break, единый для всех одинаковых случаев. Коэффициент выбранного объекта задаётся ступенчато: 25% для малого, 50% для среднего и 100% для крупного объекта относительно размера цели. Если перекрывающий объект союзный, соответствующая доля называется `friendly fire`; если вражеский, это обычная доля попаданий по перекрытию. В обоих случаях до броска строится одно и то же распределение: `hitBlocker = cover`, `hitMain = max(0, accuracy - cover)`, `miss = 100 - accuracy`; если `hitMain` равен нулю, основная цель недоступна, но перекрывающий объект всё ещё может получить попадание. Союзные и вражеские объекты используют одинаковую механику перекрытия. После каждого выстрела линия вычисляется заново, поэтому уничтожение перекрытия влияет только на последующие выстрелы. Прототип проверки сохранён в `line-of-fire-prototype.html`.

## Question

Зафиксировать понятную геометрию линии между центрами гексов и ступенчатое перекрытие 25/50/100% по отношению размеров. На каждом выстреле ближайшая перекрывающая цель получает диапазон friendly fire, вычитаемый из шанса попадания по основной цели; крупная цель может закрыть её полностью. После уничтожения перекрытия линия пересчитывается перед следующим выстрелом.
