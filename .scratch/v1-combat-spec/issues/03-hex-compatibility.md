# Матрица коллизий и совместимости гекса

Type: grilling
Status: resolved
Blocked by:

## Question
Завершить каноническую матрицу входа, прохождения, остановки и совместного нахождения для капитальных кораблей, союзных и вражеских эскадрилий, крупных объектов, местности, опасностей и создаваемых обломков. Включить принудительное перемещение, появление объектов, повторную валидацию маршрута и уничтожение на промежуточном шаге.

## Answer

Зафиксирована матрица движения v1:

- Остановиться можно в пустом допустимом гексе. Для гекса с местностью или опасностью правила соответствующего типа определяют допустимость остановки; их наличие не делает гекс занятым юнитом.
- Эскадрилья может пролететь через гекс крупного корабля или другого объекта, но не может завершить маршрут в гексе с любым объектом. Крупный корабль не может проходить через другой крупный корабль в обычных условиях.
- Юнит не может занять гекс с вражеским юнитом. Для эскадрильи соседство с вражеской эскадрильей образует перехват; зона перехвата — все шесть соседних гексов эскадрильи.
- Капитальный корабль может войти во вражеский гекс только при явно включённом действии «таранный разгон». В v1 непреднамеренный таран по инерции не возникает: обычный маршрут блокируется перед вражеским капитальным кораблём.
- Принудительное перемещение подчиняется той же матрице: несовместимый вход не выполняется и возвращает результат `blocked`.
- После появления объекта, изменения состояния гекса или уничтожения на промежуточном шаге маршрут повторно валидируется перед следующим шагом. Летальное событие немедленно прекращает маршрут; поле обломков появляется в гексе уничтожения и применяется к последующим проверкам входа и остановки.

Вопрос о непреднамеренном таране по инерции отложен в дорожную карту последующих версий и не входит в модель v1.
