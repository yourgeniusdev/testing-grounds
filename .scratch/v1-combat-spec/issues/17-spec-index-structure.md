# Структура общего индекса спецификаций v1

Type: grilling
Status: resolved

## Answer

Индекс `docs/specs/v1/README.md` включает девять тематических документов: lifecycle; deployment; movement-space; interception-disengagement-ramming; attacks-fire-cover; AA; squadrons; damage-destruction-victory; и отдельный `entities-and-assets.md`. Последний содержит только нормативную идентичность, классификацию, состав, характеристики и playtest-параметры классов кораблей, оружия и объектов поля; поведение и порядок разрешения остаются в доменных документах. Начинать следует с одного справочника, разделяя его только при существенном росте объёма.

Порядок чтения отражает зависимости правил, а не отдельный план реализации. Доменные документы могут ссылаться на конкретные разделы и якоря `entities-and-assets.md` относительными Markdown-ссылками и нормативными идентификаторами; нормативное правило хранится ровно в одном месте. Legacy-документы содержат только указатели на канонические спецификации и не дублируют правила.
