# Единый жизненный цикл урона и уничтожения

Type: grilling
Status: resolved
Blocked by: 04, 05, 09, 10, 11

## Question

Определить единый доменный процесс для оружия, friendly fire, опасностей, тарана и реакций: применение по слоям защиты, изменение стека, критические заглушки, немедленное уничтожение, создание обломков, очистка перехвата и очереди, отмена незавершённых действий и проверка полного уничтожения стороны.

## Answer

Все источники урона — оружие, friendly fire, опасность, таран и реакция — создают пакет урона и передают его в единый атомарный pipeline цели. Пакет применяется последовательно по слоям `щит → броня/прочность корпуса → целостность эскадрильи`; частично применённый пакет не откатывается, а переходы между слоями происходят внутри одной транзакции. После разрешения пакета немедленно пересчитываются производные параметры стека эскадрильи по правилам деградации.

Критическое повреждение в v1 только фиксируется как результат/событие без механического эффекта: критические заглушки, статусы и расширенные эффекты находятся вне scope. Нулевой запас последнего слоя означает уничтожение юнита. Уничтожение сначала добавляется в детерминированный набор текущего разрешения; затем для каждого уничтоженного юнита выполняются cleanup, создание поля обломков на его гексе, удаление связей перехвата, отмена его текущего маршрута/атаки/тарана, реакций и ожидающих callbacks. Уже применённый урон и созданные обломки не откатываются.

После завершения cleanup всех объектов выполняется одна проверка победы по итоговому состоянию поля. Если у стороны не осталось ни одного юнита, бой немедленно переходит в терминальное состояние, в том числе при уничтожении во время движения, реакции или другого атомарного действия; дальнейшие действия и callbacks не разрешаются. Если уничтожение активного юнита прерывает незавершённое действие, частично разрешённые предшествующие шаги сохраняются.
