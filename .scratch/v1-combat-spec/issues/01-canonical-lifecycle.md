# Каноническая машина фаз полного боя

Type: grilling
Status: resolved
Blocked by:

## Question

Какие явные состояния и переходы образуют полный цикл v1: последовательная расстановка сторон, подтверждение, формирование инициативы, ожидание до начала активации, системные действия, манёвр, атака, реакции, завершение активации и завершение боя при ликвидации стороны? Зафиксировать момент восстановления ресурсов, автоматического перехода ПВО в наблюдение и немедленных проверок победы.

## Answer

Зафиксирована необратимая машина состояний `DeploymentLeft → DeploymentRight → RoundStart → WaitDecision → ActivationStart → SystemActions → Maneuver → Attack → EndActivation → WaitDecision | RoundEnd → RoundStart | Finished`.

Левая сторона всегда расставляется первой, правая — второй. Ожидание решается до начала активации и не запускает восстановление ресурсов. Реакции v1 являются атомарными событиями внутри манёвра. Неиспользованное подходящее ПВО переходит в наблюдение при завершении активации. После любого уничтожения немедленно проверяется полная ликвидация стороны; `Finished` терминален. Этапы идут только вперёд, а перед подтверждением игрок получает все известные последствия и риски.

Каноническая спецификация: [Жизненный цикл боя v1](../../../docs/specs/v1/battle-lifecycle.md).
