# План перехода к свободной активации

## 1. Цель и стратегия

Целевое поведение определено в:

- [системе манёвров](./maneuvers.md);
- [активации и атаках оружием](./activation-and-weapon-attacks.md);
- [ADR свободного порядка действий](../adr/0001-free-order-unit-activation.md).

Переход выполняется вертикальными этапами. После каждого этапа игра должна запускаться, основной бой должен оставаться проходимым, а временные адаптеры должны сохранять прежний пользовательский сценарий там, где следующая механика ещё не внедрена.

Нельзя одновременно переписывать поиск маршрутов, исполнение движения, модель атаки и оркестрацию UI: это лишит промежуточные версии проверяемых границ.

## 2. Общие требования к каждому этапу

Каждый этап завершается только когда:

1. `npm test`, `npm run typecheck`, `npm run lint` и `npm run build` проходят;
2. добавлены автоматические тесты новых инвариантов;
3. существующий сценарий можно завершить без ручного исправления состояния;
4. подтверждённые действия не зависят от доверия к данным UI;
5. временный адаптер явно перечислен и имеет этап удаления;
6. состояние не изменяется во время предпросмотра;
7. события получают корректный контекст действия, а не устаревшую фазу.

## 3. Этап 0 — Характеризация и фундамент движения

### Цель

Сделать существующее движение пошагово корректным до изменения правил курса и активации.

### Работы

- Добавить табличные тесты `planRoutes()` для стоимости, препятствий, безопасной и рискованной политик, повторов гексов и детерминированности.
- Ввести неизменяемый план манёвра по образцу плана атаки: последовательность шагов, поворотов, стоимости и известных последствий.
- Сделать пошаговый исполнитель единственным способом изменить позицию.
- На каждом шаге списывать ресурс, разрешать выход, вход, опасности, реакции, уничтожение и остановку.
- Создавать обломки в фактическом гексе уничтожения.
- Использовать стоимость входа из единого контракта проходимости для обеих категорий юнитов.
- Исправить проход эскадрильи через крупный корабль так, чтобы прочее содержимое гекса не терялось.
- Исправить Перехват: остановка маршрута, симметричные связи со всеми соседними врагами, запрет обычного движения связанной эскадрильи.
- Включить известные ПВО и Перехват в безопасную политику.
- Сохранить контракт UI-опций манёвра как адаптер к новому плану.

### Временная совместимость

Сохраняются текущие различия движения: эскадрильи без курса, крупные корабли с ограничением одного поворота перед шагом, один манёвр перед атакой.

Временные адаптеры и удаление:

- отсутствие Курса у эскадрилий и синтетический конечный Курс крупного корабля удаляются на этапе 1;
- старый групповой Залп удаляется на этапе 2;
- один манёвр перед блоком атаки и фазовая оркестрация удаляются на этапе 3;
- одиночное поле Перехвата удаляется на этапе 1 после перевода UI на полный набор связей.

### Играбельный результат

Бой выглядит почти как раньше, но маршрут исполняется корректно по шагам и может законно прекратиться до запланированного конца.

## 4. Этап 1 — Общий курс и Манёвренность

### Цель

Перевести крупные корабли и эскадрильи на общую модель последовательностей «поворот или шаг».

### Работы

- Добавить эскадрильям курс и базовую Манёвренность в профили и runtime-состояние.
- Выбрать балансные значения так, чтобы Манёвренность эскадрилий была явно выше сопоставимых крупных кораблей без системного минимума.
- Назначать начальный курс всем юнитам по стороне развёртывания: слева направо, справа налево.
- Заменить отдельный поиск маршрутов эскадрилий общей моделью состояния «гекс + курс + расходы», сохранив различия проходимости.
- Разрешить любое число поворотов до, между и после шагов.
- Удалить ограничения одного поворота перед шагом и одного финального доворота.
- Запретить пустой маршрут, но разрешить манёвр только из поворотов.
- Сделать конечное состояние парой «гекс + курс» для всех юнитов.
- Перевести все текущие слоты «Осы» и «Мантиса», включая торпеду, на курсовые хардпоинты с передним сектором.
- Обновить отображение ориентации эскадрилий и секторов их оружия.

### Временная совместимость

Активация всё ещё использует один манёвр, после которого переходит к старому Залпу. Бюджеты технически хранят расход, но повторный манёвр пока не открыт UI.

### Играбельный результат

Все юниты движутся по одной понятной механике курса и поворотов; эскадрильи сохраняют свободу за счёт высоких профильных значений.

## 5. Этап 2 — Атаки отдельными оружейными слотами

### Цель

Заменить Залп на несколько независимых атак оружием без одновременного внедрения свободной оркестрации всех действий.

### Работы

- Ввести план атаки одного слота по одной цели.
- Убрать выбор множества слотов и `salvoCommitted` из доменного контракта.
- Сделать атакующего явным аргументом расчётов, чтобы те же примитивы могли использовать реакции ПВО.
- Проверять готовность, энергию, вид цели, сектор, дальность и линию огня для выбранного слота.
- Списывать энергию и готовность при подтверждении атаки.
- Возвращать управление к выбору следующего готового слота после разрешения.
- Разрешить разные цели для разных слотов.
- Сохранить независимые Выстрелы и масштабирование числа Выстрелов стеком эскадрильи.
- Связать ручную атаку и Наблюдение с одной готовностью.
- Реализовать минимальный UI: клик по слоту, сектор, допустимые цели, одна цель, подтверждение.

### Временная совместимость

Системные действия и единственный манёвр остаются до блока атак. После начала блока атак нельзя вернуться к движению до этапа 3.

### Играбельный результат

Игрок может выстрелить несколькими готовыми слотами по разным целям. Полный групповой предпросмотр и дополнительная полировка UI не блокируют этап.

## 6. Этап 3 — Свободный порядок действий

### Цель

Удалить фазовую оркестрацию и открыть повторяемые действия на общих остатках ресурсов.

### Работы

- Заменить `system → movement → attack` единым состоянием выбора действия после Начала активации.
- Ввести явные команды начала планирования, отмены, подтверждения и завершения активации.
- Хранить потраченные Скорость, Манёвренность и энергию на уровне активации.
- Строить сетку только после «Совершить манёвр» и только на остатки бюджетов.
- После завершённого или прерванного манёвра возвращать выбор действий.
- После атаки оружием возвращать выбор действий.
- Разрешить системные действия до, между и после манёвров и атак.
- Применять изменения максимума ресурсов к остатку без возврата расхода.
- Применять эффект нахождения после каждого манёвра; при завершении без манёвров применять его один раз.
- Накапливать уклонение по всем фактическим шагам активации.
- Сделать «Завершить активацию» явным и доступным вне разрешения действия.
- Удалить автоматическое завершение активации после атаки.
- Удалить временные адаптеры этапов 1 и 2.

### Играбельный результат

Работает целевая последовательность: манёвр → атака → системное действие → манёвр → атака другим слотом → явное завершение.

## 7. Этап 4 — Реакции, устойчивость и UX

### Цель

Закрыть интеграционные края после включения целевой модели.

### Работы

- Проверить реактивные атаки ПВО во время пошагового движения.
- Проверить Наблюдение после ручного использования или сохранения каждого слота.
- Проверить Отрыв и последующие манёвры на остатки бюджетов.
- Проверить изменение характеристик между несколькими действиями.
- Проверить уничтожение активного юнита внутри манёвра, атаки и реакции.
- Добавить журнал действий с контекстом конкретного действия вместо фазы.
- Доработать доступность кнопок, причины блокировки и остатки ресурсов.
- Добавить интеграционные сценарии с несколькими целями, опасностями, Перехватом и ПВО.
- Удалить устаревшую терминологию Залпа и фаз из UI и событий.

### Играбельный результат

Целевая модель устойчива в полном боевом сценарии и объясняет игроку, почему конкретное действие доступно или заблокировано.

## 8. Матрица ключевых тестов

| Область | Обязательные сценарии |
|---|---|
| Планировщик | несколько поворотов в гексе; разворот 180° и шаг; конечный курс; отсутствие пустого маршрута; детерминированность |
| Бюджеты | два манёвра на общий остаток; уменьшение и увеличение максимума; отсутствие переноса между активациями |
| Проходимость | крупный корабль блокируется юнитами; эскадрилья проходит крупный корабль; запрет остановки; объект блокирует всех |
| Исполнение | опасность на фактическом шаге; досрочная остановка; уничтожение и обломки в текущем гексе |
| Перехват | все соседние враги; симметрия; прекращение маршрута; запрет движения; успешный Отрыв и остаток бюджета |
| Атаки | один слот и одна цель; разные слоты по разным целям; общая энергия; готовность; независимые Выстрелы |
| Секторы | курс крупного корабля и эскадрильи; курсовые хардпоинты; сектор после промежуточного манёвра |
| Наблюдение | ручная атака снимает реакцию; неиспользованный слот реагирует; реакция расходует готовность |
| Оркестрация | свободное чередование; отмена предпросмотра; атомарность действия; явное завершение |
| Нахождение | после каждого манёвра; после поворота на месте; один раз при завершении без манёвров |
| Уклонение | сумма фактических шагов нескольких манёвров; атака не сбрасывает бонус; поворот влияет по своей формуле |

## 9. Риски и меры

- **Взрыв пространства поиска из-за поворотов на месте.** Использовать доминирование состояний по паре «гекс + курс» и расходам, сохраняя посещённые гексы в конкретном маршруте.
- **Двойное списание ресурсов между планом и исполнением.** План остаётся неизменяемым описанием; только пошаговый исполнитель меняет состояние.
- **Расхождение UI и домена.** Все команды повторно валидируются доменным слоем; UI не является источником легальности.
- **Смешение старых фаз и новых действий.** Совместимость изолируется адаптерами с указанным этапом удаления.
- **Повторные эффекты нахождения.** Хранить факт совершения манёвра в активации и применять завершение без движения отдельно.
- **Потеря Наблюдения при миграции атак.** Готовность остаётся единственным источником права ручной или реактивной атаки.

## 10. Вне текущего перехода

- баланс конкретных значений Манёвренности эскадрилий;
- новые типы башенных или специальных эскадрильных хардпоинтов;
- формулы урона, уклонения, Отрыва и столкновений;
- вынужденное инерционное движение и выход за границу;
- полная переработка инициативы, ожидания или условий победы.
