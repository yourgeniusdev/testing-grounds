# Нормативные спецификации боя v1

Этот каталог содержит канонические правила полного боевого цикла v1. При конфликте с корневыми initial/legacy-документами приоритет имеют документы этого каталога.

## Область действия

Спецификации описывают тестовый hot-seat/sandbox-бой: последовательную расстановку сторон, раунды и активации, движение и реакции, атаки, урон, уничтожение и победу через полное уничтожение одной стороны.

## Порядок чтения

Порядок отражает зависимости правил и не является отдельным планом реализации.

1. [Жизненный цикл боя](battle-lifecycle.md)
2. Сущности и нормативные параметры
3. Расстановка и пространство поля
4. Движение, перехват, отрыв и таран
5. Линия огня, атаки и укрытие
6. [ПВО и наблюдение](aa.md)
7. [Деградация эскадрилий](squadrons.md)
8. [Урон, уничтожение и победа](damage-destruction-victory.md)
