# Нормативные спецификации боя v1

> **Архив:** реализация v1 признана неудачной. Эти документы не являются текущей спецификацией, но сохраняются как источник для будущих документов.

Этот каталог содержит бывшие канонические правила полного боевого цикла v1. Их прежний приоритет над initial/legacy-документами сохранён только как исторический контекст.

## Область действия

Спецификации описывают тестовый hot-seat/sandbox-бой: последовательную расстановку сторон, раунды и активации, движение и реакции, атаки, урон, уничтожение и победу через полное уничтожение одной стороны.
